# Сашок стишок — personal reading tracker

Готовый статический сайт для публикации на GitHub Pages.

## Возможности

- библиотека книг;
- статусы «Читаю / Прочитано / В планах»;
- прогресс по страницам;
- добавление собственных книг;
- цели чтения;
- статистика;
- заметки и цитаты;
- экспорт библиотеки в JSON;
- тёмная тема;
- адаптивная версия для телефона;
- хранение данных в `localStorage`, без сервера.

## Запуск

Откройте `index.html` локально или загрузите папку в GitHub.

### GitHub Pages

1. Создайте репозиторий.
2. Загрузите все файлы из архива в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Выберите `main` и `/root`.
6. Сохраните настройки.

Через некоторое время сайт будет доступен по адресу GitHub Pages.
