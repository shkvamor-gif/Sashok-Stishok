# Сашок стишок 3.0

Личный трекер чтения с каталогом книг.

## Что добавлено в 3.0

- поиск книг через **Open Library Search API**;
- поиск по названию, автору и ISBN;
- реальные обложки книг из Open Library Covers;
- добавление найденной книги в личную библиотеку;
- ISBN-поиск;
- попытка сканирования ISBN камерой через `BarcodeDetector`;
- карточка книги с ISBN, годом и издателем;
- сохранение библиотеки в `localStorage`;
- прогресс страниц;
- таймер чтения с завершением сессии;\n- после таймера можно указать количество страниц и необязательную заметку;\n- история последних сессий чтения;
- календарь;
- статистика;
- цели;
- заметки;
- тёмная тема;
- экспорт JSON;
- мобильная версия.

## GitHub Pages

Загрузите `index.html`, `styles.css`, `app.js` в корень репозитория и используйте GitHub Pages → GitHub Actions → Static HTML.

## API

Версия 3.0 использует Open Library для поиска и обложек. API вызывается напрямую из браузера, поэтому сервер для базового поиска не требуется.

Документация:
https://openlibrary.org/dev/docs/api/search
https://openlibrary.org/dev/docs/api/covers

Для публичного проекта соблюдайте правила использования Open Library API и не используйте его для массовой загрузки данных.

Сайт является самостоятельной реализацией «Сашок стишок» и не копирует исходный код или фирменный интерфейс Leero.


## Сессия чтения

1. Выбери книгу.
2. Нажми «Старт».
3. После чтения нажми «Стоп».
4. Укажи количество прочитанных страниц.
5. При желании добавь заметку.
6. Нажми «Сохранить сессию».

Сессия попадёт в календарь, статистику, историю и прогресс книги. Заметка также появится в разделе «Заметки».
