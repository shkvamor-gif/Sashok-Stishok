Полностью переработанная многостраничная версия личного читательского дневника.

## Страницы
- Обзор
- Библиотека
- Найти книгу / Open Library / ISBN / камера
- Сессия чтения с выбором книги перед стартом
- Календарь
- Продвинутая статистика
- Заметки: мысли, цитаты, отзывы
- Цели
- Коллекции
- Серии книг
- Мой профиль и достижения
- Импорт / экспорт backup

## Supabase
Конфигурация находится в `supabase-config.js`. Используется только публичный publishable/anon key. Схема RLS — `supabase.sql`.

Если таблицы уже созданы в Supabase из v3.x, структура совместима: новые сущности хранятся внутри JSON `user_data`.
