## Supabase
Конфигурация находится в `supabase-config.js`. Используется только публичный publishable/anon key. Схема RLS — `supabase.sql`.

Если таблицы уже созданы в Supabase из v3.x, структура совместима: новые сущности хранятся внутри JSON `user_data`.

## GitHub Pages
Загрузи файлы архива в корень репозитория и включи GitHub Pages. `index.html` — главная страница.


## v4.1 — Cozy Editorial UI
Главная страница переработана под фирменный макет: полноэкранный библиотечный hero, тёмно-зелёная навигация, кремовые карточки, блок профиля, сессия чтения, статистика, календарь и история. Все функции v4 сохранены.


## V4.3 исправления

- Добавлена отдельная кнопка «Создать аккаунт» на всех страницах.
- Регистрация теперь вынесена в полноценное окно аккаунта с именем, email и паролем.
- Для нового аккаунта локальная библиотека автоматически загружается в Supabase после регистрации/входа, если облачных данных ещё нет.
- Добавлена автоматическая синхронизация между открытыми устройствами через Supabase Realtime.
- На странице профиля есть кнопка «Синхронизировать сейчас» и выход из аккаунта.
- Исправлена кнопка «＋ Добавить книгу» в библиотеке — она открывает форму добавления.
- Главный фон заменён на отдельный баннер только с библиотекой и книгами, без обрезанного человека.
